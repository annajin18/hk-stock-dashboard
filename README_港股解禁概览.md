# 港股解禁概览 — 运行说明

## 功能概述

以智通财经限售解禁数据为主 + Excel为辅 + 实时行情，自动生成静态网页 `hk_unlock_overview.html`，双击浏览器即可打开。

顶部导航可切换到「港股通入通看板」（`hk_ggt_ru_tong.html`），两个页面相互跳转。

## 文件说明

| 文件 | 作用 |
|------|------|
| `template.html` | HTML 模板（UI 样式、交互逻辑） |
| `generate_unlock_html.py` | 主脚本：数据采集、校验、HTML 生成 |
| `基石投资者0810.xlsx` | 基石投资者解禁数据（辅助源：补充智通财经缺失的股票和投资者明细） |
| `hk_unlock_overview.html` | 最终产物（脚本生成） |
| `unlock_data.json` | 中间 JSON 数据（调试用） |

## 依赖安装

```bash
pip install openpyxl requests beautifulsoup4 pdfplumber pymupdf
```

完整依赖列表：
- `openpyxl` — 读取 Excel
- `requests` — HTTP 请求（行情API、港交所、CCASS）
- `beautifulsoup4` — HTML 解析（CCASS 页面、港交所搜索页）
- `pdfplumber` — PDF 表格解析（配售公告）
- `pymupdf` — PDF 文本提取（配售公告备选方案）

## 执行命令

```bash
cd D:\港股交易app
python generate_unlock_html.py
# 快速生成（跳过CCASS校验，页面会打「未经过CCASS交叉校验」标签）：
python generate_unlock_html.py --no-ccass
# 指定基准日期（默认今天）：
python generate_unlock_html.py --date 2026-08-11 --no-ccass
```

## 解禁日历

日历模块固定展示「本周 + 下周」两个自然周的周一至周五（共 10 个工作日格子），
每个格子显示当日解禁的股票（市值/股数/解禁类型），无解禁的日期显示为空。

解禁股数交叉校验规则：公告/Excel 披露股数 VS CCASS 托管可解禁股数，
偏差 <5% 正常展示、5%~15% 加黄色提示、>15% 丢弃。
当 CCASS 不可用（或使用 `--no-ccass`）时不做股数丢弃，页面不展示校验标签，仅在运行日志中提示。

## 数据源与合并规则

- **智通财经限售解禁**（`betaapi.zhitongcaijing.com/v12/ctoneinvestor/limit-sale-list.html`）为主要数据源，
  接口实时更新，无需手动维护：
  解禁日、解禁股数、上市日、限售期以智通为准。
- **Excel（基石投资者0810.xlsx）为辅助源**：
  用于补充智通财经缺失的股票，以及提供逐投资者明细（机构名称、认购股数、金额、占比）。
- 同一只股票两个来源都有时，日期/股数以智通为准，投资者明细优先用 Excel，
  差异会在运行日志中提示。
- 解禁市值始终本地计算：解禁股数 × 最新港股收盘价，不复用第三方市值字段。

## 数据流程

```
Step 1: 加载 Excel → 基石解禁数据（基石投资者0810.xlsx）
Step 2: 港交所搜索 → 补充配售/股东锁仓公告
Step 3: 拉取行情 → 腾讯财经API批量取最新收盘价
Step 4: CCASS校验 → 对本月解禁股票查托管量
Step 5: 合并计算 → 解禁市值=股数×价格，偏差分类，过滤
Step 6: 生成HTML → 注入模板，输出 hk_unlock_overview.html
```

## 数据校验规则

| 偏差范围 | 处理方式 |
|---------|---------|
| < 5% | 正常展示 |
| 5% ~ 15% | 黄色标签「数据存在偏差，请查阅原始公告」 |
| > 15% | 丢弃该条目，写入日志 |

## CCASS 降级

如果 CCASS 接口限流/不可用，对应条目标记「未经过CCASS交叉校验，仅供参考」。

## 注意事项

1. **港交所请求延时**：脚本自动在每次请求间延时 2-5 秒，避免触发反爬。
2. **网络依赖**：行情API和CCASS接口需要外网访问。
3. **数据时效**：腾讯行情为实时数据，CCASS有 T+2 延迟。
4. **配售公告**：港股解禁不需要单独公告，部分配售公告PDF可能无法成功解析文本（扫描件/图片）。
5. **仅限基石解禁**：Excel 数据主要覆盖基石投资者解禁，国际配售和股东配售依赖港交所公告搜索补充。
