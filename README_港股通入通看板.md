# 港股通入通看板 — 运行说明

## 功能概述

单文件静态网页 `hk_ggt_ru_tong.html`，双击用浏览器打开后，自动从智通财经数据中心公开接口实时拉取港股通标的调整预测数据，聚焦「入通」名单，并展示五档纳入市值门槛、调整日历与生效倒计时；榜单 Tab 内显示各分类数量。

无需安装依赖、无需启动本地服务、无需 Python 脚本。

## 使用说明

```bash
cd D:\港股交易app
start hk_ggt_ru_tong.html
```

页面打开后自动加载数据，也可点击「重试」重新拉取。首次打开需要联网（接口基址 `https://betaapi.zhitongcaijing.com`，支持跨域）。

## 页面功能

| 功能 | 说明 |
|------|------|
| 概览卡片 | 预计入通 / 调出 / 维持 / 标的池 / 全部数量，入通与调出市值，上期预测命中回顾 |
| 榜单 Tab | 入通（默认）、调出、维持、标的池、全部，每个 Tab 显示对应数量 |
| 子筛选 | 入通、调出 Tab 可切换「预测名单 / 候选名单」；全部 Tab 可按市值覆盖率区间筛选（94%-96% / >96% / <94%） |
| 排序 | 「预测名单」默认按生效日期由近到远排列；其他榜单默认按市值覆盖率降序。点击「市值覆盖率」表头可切换为该列的升 / 降序 |
| 分页 | 每页 50 条，底部「加载更多」追加下一页 |
| 搜索 | 顶部搜索框按股票代码 / 名称过滤当前已加载数据 |
| 明暗模式 | 顶部开关切换浅色 / 深色主题 |
| 最新调整公布 | 榜单筛选栏右侧入口，点击弹出最近已公布的港股通标的调整记录（纳入 / 调出 + 股票 + 日期，数据来源：智通财经） |
| 调整日历 | 数据状态条下方显示距离正式生效的天数，以及「数据截止（12-31 / 06-30）→ 结果公布 → 正式生效」三个关键时间点的进度时间轴 |
| 纳入门槛概览 | 调整日历下方列出 5 个入通标准的市值门槛：小型股 / 中型股 / 大型股 / 快速纳入 / 特殊快速纳入，并附已入通标的的维持 / 调出参考门槛 |
| 个股详情 | 点击表格任意一行，弹出该股入通资格检测报告：市值 / 流动性 / 上市时长逐项结论、月度换手率对照、上下期切换 |
| 规则说明 | 页面底部「预测规则说明」可展开：四条入通路径表格（常规纳入 / 中型股季度快纳 / 大型股极速通道 / AH 股），含适用对象、市值门槛（与上方纳入门槛概览对应）、考察口径、入通时点、速度评级，附同股不同权（-W）特殊说明 |

## 数据来源与字段说明

数据来自智通财经数据中心（`https://betaapi.zhitongcaijing.com/hkmarket/ggt-ctb/*` 系列接口），主要字段：

- `SecuAbbr` / `SecuCode`：股票名称 / 代码
- `AvgMarketValue`：日均市值
- `MarketValueRatio`：市值覆盖率（可排序）
- `price` / `DbPrice`：现价 / 参考价
- `ForecastStatus`：预测状态（1 预测纳入、2 预测调出、3 维持、0 候选）
- `IndexComponentType`：恒生综指类型
- `is_ggt`：是否已是港股通标的
- `AdjustMode`：调整方式（定期纳入 / 定期调出 / 季度快速纳入）
- `EffectiveDate`：生效日期

个股详情（点击行后）来自 `detection.html` 检测接口，展示：

- 检讨期与基准日
- 逐项结论：市值、流动性、上市时长是否达标，以及最终「预计纳入 / 预计不会纳入」判断
- 参考指标：上市日期、上市时长、日均市值、检讨期成交额
- 月度换手率明细（对照参考值，标注达标 / 未达标）
- 上期 / 下期切换，可对比同一只股票前后两期的条件变化
- 纳入门槛（单只股票当前周期的市值门槛）

## 注意事项

1. **网络依赖**：数据实时从第三方接口拉取，接口变更或限流时页面会提示「数据加载失败」，可稍后重试。
2. **预测属性**：入通 / 调出为预测结果，最终名单以沪深交易所与港交所正式公告为准。
3. **搜索范围**：搜索仅对当前已加载的数据生效，继续翻页加载后搜索同样适用。
4. **数据时效**：数据按交易日更新，行情价格可能有延迟。
5. **检测接口**：个股检测依赖第三方检测接口，个别股票可能无检测数据或加载失败，可点击弹窗内「重试」。
