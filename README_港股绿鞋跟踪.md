# 港股绿鞋跟踪 — 运行说明

## 功能概述

追踪港股新股超额配售（绿鞋）使用情况：绿鞋额度、已行使/剩余、稳价人、绿鞋日历（预测/修正/实际）、每日使用明细、券商净买卖 Top10、价格走势。

自动生成两个静态网页，双击浏览器即可打开：

- `hk_greenshoe.html` —— 绿鞋跟踪首页（统计卡片 + 全量列表 + 筛选/搜索/分页）
- `greenshoe_detail.html` —— 单只股票绿鞋详情页（通过 `?code=06915` 参数打开）

顶部导航可切换到「港股解禁概览」（`hk_unlock_overview.html`）和「港股通入通看板」（`hk_ggt_ru_tong.html`）。

## 文件说明

| 文件 | 作用 |
|------|------|
| `generate_greenshoe_html.py` | 主脚本：数据采集、合并计算、HTML 生成 |
| `greenshoe_template.html` | 首页模板（UI 样式、交互逻辑） |
| `greenshoe_detail_template.html` | 详情页模板 |
| `hk_greenshoe.html` | 最终产物：绿鞋跟踪首页 |
| `greenshoe_detail.html` | 最终产物：单股详情页（?code=XXXXX） |
| `greenshoe_data.json` | 中间结构化数据（调试用） |

## 数据来源

1. **TradeGoMart 绿鞋追踪**（`cloudapi.livereport8.com/livereport/GreenShoeTrace/*`，跨域开放，页面可直接调用）：
   - 绿鞋股票名单
   - 每只股票的绿鞋日历（每日「预测 / 修正 / 实际」三档金额与股数）、初始额度 / 累计已用 / 剩余可用 / 今日使用
   - 券商净买卖 Top10、绿鞋席位追踪统计
2. **腾讯财经实时行情**（`qt.gtimg.cn`）与日 K 线（`web.ifzq.gtimg.cn`）：现价、较发行价、价格走势图
3. **本地 Excel 补充**（可选，缺失时自动跳过）：
   - `C:\Users\admin\Desktop\首发信息一览.xlsx` —— 发行价、超额配售数量（用于交叉核对）
   - `C:\Users\admin\Desktop\港股-IPO暗盘行情.xlsx` —— 暗盘 / 上市首日行情

## 数据流程

```
Step 1: TradeGoMart 绿鞋股票名单
Step 2: 并发拉取每只股票的绿鞋日历/汇总/券商明细
Step 3-4: 读取本地 Excel（发行价、超额配售数量、暗盘/首日）
Step 5: 腾讯行情批量取最新价
Step 6: 合并计算 → 状态/已行使占比/保护期消耗
Step 7: 注入模板 → 输出 hk_greenshoe.html + greenshoe_detail.html
```

## 状态规则

| 状态 | 判定 |
|------|------|
| 绿鞋保护中 | 未到期且额度未用尽 |
| 额度耗尽 | 累计已用 / 初始额度 ≥ 99.995%（优先于到期） |
| 已到期 | 超过绿鞋到期日 |
| 暂无数据 | 接口无绿鞋日历且无额度 |

绿鞋到期日取自绿鞋日历 `endDate`；发行价优先取 Excel，缺失时用「初始额度金额 / 初始额度股数」反推（已与招股书核对一致）。

## 页面功能

| 功能 | 说明 |
|------|------|
| 统计卡片 | 绿鞋标的数 / 当前保护期 / 有回购操作 / 已到期完结 |
| 列表 | 按上市时间倒序，含稳价人、发行价、现价、较发行价、额度、已行使占比（迷你进度条）、剩余、状态 |
| 筛选 | 全部 / 保护中 / 已到期 / 额度耗尽 / 暂无数据 |
| 搜索 | 按代码或名称过滤，分页每页 20 条 |
| 详情页 | 额度四卡片、已行使占比与有效期消耗进度、绿鞋日历、价格走势（收盘价 + 每日绿鞋买入）、每日使用明细、券商净买卖 Top10、追踪统计 |
| 刷新数据 | 页面内实时重新拉取绿鞋数据与行情（需联网） |
| 加入关注 | 写入浏览器 localStorage，本地保存关注列表 |

## 注意事项

1. **网络依赖**：生成脚本与页面刷新都需要访问 TradeGoMart 接口和腾讯行情，接口变更或限流时页面会提示刷新失败，可稍后重试。
2. **数据时效**：绿鞋日历含「预测 / 修正 / 实际」三档，实际数据以公司公告为准；TradeGoMart 数据可能有延迟。
3. **Excel 路径**：若桌面 Excel 文件被移动/改名，脚本会自动跳过该数据源（仅影响发行价交叉核对与暗盘/首日展示）。
4. **数据一致性**：接口中金额口径与股数口径偶有差异（如已行使占比按金额计算），页面统一按金额计算并已注明。
