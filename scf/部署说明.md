# 腾讯云 SCF 云函数部署说明

## 1. 准备工作

- 注册腾讯云账号并完成实名认证(需要身份证),地址: https://cloud.tencent.com
- 打开云函数控制台: https://console.cloud.tencent.com/scf

## 2. 创建云函数

1. 在云函数控制台点 **新建**
2. 函数类型选择:**Web 函数**
3. 函数名称填:`hk-data-proxy`
4. 地域建议选 **广州** 或 **上海**
5. 运行环境选 **Python 3.9**(或更高)
6. 代码提交方式选 **本地上传 zip**,直接上传 `scf/hk-data-proxy.zip`
   (zip 里已包含 `index.py` 和 `scf_bootstrap` 启动文件,不要解压,直接传 zip)
7. 点 **完成** 创建

创建成功后,控制台会显示一个访问地址,类似:

```
https://hk-data-proxy-xxxxxxx.ap-shanghai.app.tcloudbase.com
```

这个地址就是你的后端接口地址,记下来。

## 3. 验证接口

浏览器打开(或命令行请求)以下地址,能看到绿鞋股票名单即成功:

```
https://<你的云函数地址>/api/greenshoe/list
```

行情接口测试:

```
https://<你的云函数地址>/api/quote?codes=hk00700,hk09988
```

## 4. 免费额度说明

SCF 每月有免费调用次数和资源用量额度,个人网站完全够用;超出部分按量计费(非常便宜)。在"函数配置"里可以设置并发上限和超时时间(建议超时 30 秒)。
